# Earn Money

تطبيق Android تأسيسي لمهام وعروض المكافآت، مع Backend مستقل.

> **تنبيه:** هذه نسخة تأسيسية فقط. لا يوجد حاليًا مزود عروض مباشر أو حسابات مستخدمين أو محفظة نقدية أو سحب أموال مفعّل. لا تعتبر أي بيانات تجريبية أرباحًا حقيقية.

## مكونات المشروع
- `app/`: تطبيق Android باستخدام Kotlin وJetpack Compose.
- `backend/`: خادم Node.js بسيط يتضمن نقطة فحص صحة الخدمة.
- `docs/product-foundation.md`: نطاق المنتج وضوابط المكافآت والمدفوعات.
- `docs/technical-roadmap.md`: مراحل التنفيذ وبوابات الإطلاق.

## تشغيل Backend محليًا
يتطلب Node.js 20 أو أحدث:

```bash
cd backend
npm start
```

ثم افتح `GET http://localhost:3000/health`.

## فتح تطبيق Android
افتح جذر المستودع في Android Studio، وانتظر Gradle Sync، ثم شغّل وحدة `app` على محاكي أو جهاز Android.

## إعدادات مهمة
- معرّف الحزمة المبدئي: `com.minodanger.earnmoney`، ويجب التحقق من توفره قبل النشر.
- لا تضع مفاتيح API أو أسرار التوقيع أو بيانات قواعد البيانات داخل التطبيق أو المستودع.
- لا تفعّل السحب أو تعرض رصيدًا قابلًا للسحب قبل اعتماد مزود يسمح صراحةً بالمكافآت النقدية واختبار دورة الدفع كاملة.

## التطوير
يتم العمل حاليًا على الفرع `setup/initial-foundation`. لا تدمج إلى `main` قبل إتمام البناء والاختبارات ومراجعة التغييرات.
