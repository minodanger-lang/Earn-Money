# Earn Money

تطبيق Android عربي لمهام وعروض المكافآت، مع Backend مستقل ولوحة إدارة أولية.

> **حالة المشروع:** واجهات Android الأساسية موجودة، وخادم API وقاعدة بيانات Supabase ولوحة إدارة أولية تمت إضافتها على فرع التطوير. لا يوجد حتى الآن مزود عروض معتمد أو مكافآت نقدية أو سحب حقيقي مفعّل.

## المكونات
- `app/`: تطبيق Android باستخدام Kotlin وJetpack Compose (الرئيسية، المهام، المحفظة، حسابي).
- `backend/`: Node.js API لتسجيل الحسابات وتسجيل الدخول وقراءة المهام والمحفظة وواجهات إدارة محمية.
- `database/migrations/`: مخطط PostgreSQL مبدئي لـ Supabase.
- `admin/index.html`: لوحة إدارة عربية أولية.
- `docs/backend-setup.md`: خطوات إعداد Supabase ومتغيرات الخادم.
- `docs/product-foundation.md`: نطاق المنتج وضوابط المكافآت والمدفوعات.
- `docs/technical-roadmap.md`: مراحل التنفيذ وبوابات الإطلاق.

## تشغيل Backend محليًا
يتطلب Node.js 20 أو أحدث:

1. أنشئ مشروع Supabase وطبّق `database/migrations/001_initial_schema.sql`.
2. انسخ `backend/.env.example` إلى ملف إعدادات خاص غير مرفوع إلى Git.
3. أضف بيانات Supabase ومُعرّفات المسؤولين إلى متغيرات البيئة.
4. شغّل:

```bash
cd backend
npm install
npm start
```

اختبر `GET http://localhost:3000/health`. تفاصيل بقية المسارات في `docs/backend-setup.md`.

## لوحة الإدارة
افتح `admin/index.html` من خلال استضافة محلية/خاصة، ثم أدخل عنوان API وحساب مسؤول. يجب إضافة UUID الخاص بحساب المسؤول إلى `ADMIN_USER_IDS` على الخادم. لا تضع مفاتيح Supabase السرية في المتصفح.

## بناء Android
افتح جذر المستودع في Android Studio، وانتظر Gradle Sync، ثم شغّل وحدة `app` على محاكي أو جهاز Android. يتم أيضًا اختبار بناء Debug APK عبر GitHub Actions.

## ضوابط الأموال والأمان
- لا تضع مفاتيح API أو مفاتيح الخدمة أو أسرار التوقيع أو بيانات قواعد البيانات داخل APK أو Git.
- لا تُضف رصيدًا قابلًا للسحب من حدث صادر من التطبيق؛ يجب التحقق من تأكيد المزود على الخادم ومنع تكرار المعاملات.
- لا تُفعّل السحب قبل اعتماد مزود يسمح صراحةً بالمكافآت النقدية في مصر، والتحقق من وسيلة الدفع واستلام دفعة ناشر فعلية.
- لا تستخدم إعلانات AdMob العادية كمصدر لمكافآت نقدية للمستخدمين.
- لا تعد المستخدمين بدخل ثابت؛ الأرباح تعتمد على العروض والتحويلات والرسوم وشروط المزود.

## فروع التطوير
يتم العمل حاليًا على `setup/initial-foundation`. فرع `main` لم يتم دمجه أو تعديله. لا تدمج قبل نجاح الاختبارات ومراجعة إعدادات الاستضافة والمزود.
